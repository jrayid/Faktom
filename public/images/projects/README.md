# Project photographs

Add project photographs here using a project slug as the file name, for example:

- `julius-berger-onitsha-owerri-line-relocation.webp`
- `kodi-hitech-owerri-orlu-line-relocation.webp`
- `airtel-site-reactivations.webp`
- `airtel-transformer-installations.webp`

Use WebP or JPG files around 1600 x 1000 pixels and under 300 KB. Add each image path and a descriptive `alt` value to that project's `photos` array in `src/data/projects.ts`.
